Resumen de los comandos
==========================
1)Inicializa el repositorio y crea la rama dev:

git init
git checkout -b dev


2)Agrega y haz commit de tus archivos en dev:

git add .
git commit -m "Mensaje del commit"


3)Empuja la rama dev al repositorio remoto:

git push -u origin dev


4)Cuando termines de trabajar en dev, fusiona los cambios con main:

git checkout main
git merge dev
git push origin main


5)Elimina la rama dev (opcional):

git branch -d dev
git push origin --delete dev


----------CARGAR VERSIONES-----------
1)crear tag (version local)
git tag v1.0
git tag -a v1.0 -m "Primera version"

2)Enviar (PUSHEAR) el tag a git
git push origin v1.0

3)Ver todos los Tag
git tag

4)Volver al estado anterior o al tag
git checkout v1.0
git checkout -b nueva-rama-v1

----------Modificar Tags-----------
1.Debes estar en la rama donde hiciste los cambios y luego de agregar y commitear....

2. Borrar el tag v1.1 localmente
git tag -d v1.1

3. Volver a crear el tag con el nuevo commit
git tag v1.1

4. Subir el nuevo tag a GitHub (sobrescribiéndolo)
Primero, borrá el tag anterior del remoto:
git push origin :refs/tags/v1.1

Luego subí el nuevo tag:
git push origin v1.1
